# QuickSeva - Home Service Booking Fullstack Project

QuickSeva is a modern full-stack home service booking platform where customers can instantly book trusted workers for daily services like hair cutting, cooking, massage, painting, beauty parlour, cleaning and more.

## Tech Stack

* Frontend: React.js, Vite, CSS
* Backend: Node.js, Express.js
* Database: MongoDB, Mongoose
* API: REST API
* Routing: React Router DOM
* HTTP Client: Axios

## How to Run

### Backend

```bash
cd backend
npm install
npm run dev
```

Backend runs on:
`http://localhost:5000`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:
`http://localhost:5173`

## API Endpoints

* GET `/api/services`
* GET `/api/bookings`
* POST `/api/bookings`
* PATCH `/api/bookings/:id/status`
* PATCH `/api/bookings/:id/location`
* DELETE `/api/bookings/:id`
